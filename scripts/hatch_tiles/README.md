Hatch tiles rasterised (256 px, greyscale, seamless) from FreeCAD 1.x TechDraw's
`share/Mod/TechDraw/Patterns/*.svg` (FreeCAD, LGPL-2.0-or-later). Used by
`scripts/revit_plans.py` (`hatch_layer`) as the standard CAD fills: herringbone,
basketweave parquet (earth), brick, aggregate concrete, wood grain, plus grid,
diamond grids (cross, zinc), rhythmic diagonals (steel, aluminium, cuprous),
glass dashes, skewed grid (plastic).
